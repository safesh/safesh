# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✓         |

Only the latest release receives security fixes. Upgrade before reporting.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use GitHub's private vulnerability reporting instead:
👉 **[Report a vulnerability](https://github.com/safesh/safesh/security/advisories/new)**

You will receive an acknowledgement within 48 hours and a resolution timeline once the report is triaged. We aim to release a fix within 14 days for critical issues.

## Scope

In-scope: `safesh` binary behavior, dependency vulnerabilities, supply-chain issues.  
Out-of-scope: vulnerabilities in scripts that `safesh` analyzes (those are user input).
